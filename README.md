
# Bank of Baku

**Bank of Baku** layihəsi müasir bank xidmətlərinin onlayn təqdimatını hədəfləyən, istifadəçi dostu və responsiv dizayna malik front-end tətbiqidir. Layihə, müştərilərin bank əməliyyatlarını daha asan və rahat şəkildə həyata keçirmələrini təmin edir.

## Layihə Haqqında
Bank of Baku layihəsi, müasir bank sistemlərini və xidmətlərini onlayn mühitdə təqdim etmək üçün hazırlanmışdır. Bu tətbiq vasitəsilə müştərilər:
- Hesablarına giriş edə bilər,
- Əməliyyatlarını izləyə bilər,
- Pul köçürmələri və ödəniş əməliyyatlarını asanlıqla həyata keçirə bilərlər.
